# file-loading

Markdown ファイルの読み込み・新規ファイル扱い・再読込・エラー処理。

## ADDED Requirements

### Requirement: Load file at startup

システムは `medit <path>` の形式で起動され、指定された Markdown ファイルを UTF-8 として読み込んで表示を開始する（SHALL）。引数がちょうど 1 つでない場合は usage を標準エラー出力へ表示して非 0 で終了する（SHALL）。指定パスがディレクトリまたは読み取り不能な場合はエラーメッセージを標準エラー出力へ表示して非 0 で終了する（SHALL）。

#### Scenario: 既存ファイルを開く

- **WHEN** 存在する `README.md` を引数に `medit README.md` を実行する
- **THEN** ファイル内容が読み込まれ、レンダリング表示が開始される

#### Scenario: 引数が不正な場合は起動しない

- **WHEN** 引数なし、または 2 つ以上の引数で起動する
- **THEN** usage が標準エラー出力に表示され、非 0 の終了コードで終了する

#### Scenario: 読み込めないパスはエラー終了する

- **WHEN** ディレクトリや読み取り権限のないパスを引数に起動する
- **THEN** エラーメッセージが標準エラー出力に表示され、非 0 の終了コードで終了する

### Requirement: Nonexistent path opens as new file

システムは存在しないパスを指定された場合、新規ファイルとして空の内容で表示を開始する（SHALL）。この時点ではファイルを作成しない（SHALL）。ステータスバーに新規ファイルであることを示す表示を行う（SHALL）。

#### Scenario: 存在しないパスは新規扱い

- **WHEN** 存在しないパス `new.md` を引数に起動する
- **THEN** 空の内容で Viewer が起動し、ステータスバーに新規ファイルであることが表示される
- **THEN** `new.md` はディスク上に作成されていない

### Requirement: Manual reload

システムは `r` キーでファイルを再読込し、最新の内容を再レンダリングして表示する（SHALL）。再読込時にファイルが存在しない・読み取れない場合は、直前の表示内容を維持したままステータスバーにエラーメッセージを表示する（SHALL）。

#### Scenario: r キーで外部変更が反映される

- **WHEN** 表示中のファイルが外部で変更された後に `r` を押す
- **THEN** 最新の内容が再レンダリングされて表示される

#### Scenario: 再読込失敗時は表示を維持する

- **WHEN** 表示中のファイルが外部で削除された後に `r` を押す
- **THEN** 直前の表示内容が維持され、ステータスバーにエラーメッセージが表示される
